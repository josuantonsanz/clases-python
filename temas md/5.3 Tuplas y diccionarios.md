# Tuplas y Diccionarios: Organizando datos

Hasta ahora hemos trabajado mucho con listas. Son geniales porque podemos añadir, quitar y cambiar cosas cuando queramos. Pero, ¿qué pasa si tenemos datos que **no deberían cambiar nunca**? ¿O qué pasa si queremos buscar un dato por su nombre y no por su posición numérica?

Hoy vamos a ver dos estructuras fundamentales en Python: las **Tuplas** y los **Diccionarios**.

## 1\. Tuplas (listas inmutables)

Imagina que estás programando un videojuego y defines el tamaño de la pantalla. No querrías que, por error, una parte del código cambiara el ancho de la ventana a mitad de la partida.

Para guardar colecciones de elementos que no deben cambiar, Python nos ofrece las **tuplas**. En términos técnicos, decimos que son **inmutables**.

### Definiendo una tupla

Una tupla es casi idéntica a una lista, pero con una diferencia visual clave: usamos **paréntesis `()`** en lugar de corchetes `[]`.

```python
# Una lista (se puede cambiar)
dimensiones_lista = [200, 50]

# Una tupla (NO se puede cambiar)
dimensiones = (200, 50)
```

Para acceder a los datos, lo hacemos igual que en las listas, usando el índice:

```python
print(dimensiones[0]) # Muestra 200
print(dimensiones[1]) # Muestra 50
```

### ¿Qué pasa si intentamos cambiarla?

Si intentamos modificar una tupla, Python lanzará un error.

```python
dimensiones = (200, 50)
# dimensiones[0] = 250 # Esto dará un TypeError.
```

### Sobrescribir una tupla

Aunque no podemos cambiar los elementos *dentro* de la tupla, sí podemos asignar un **nuevo** valor a la variable completa si es necesario actualizar todo el conjunto.

```python
dimensiones = (200, 50)
print("Dimensiones originales:")
for dim in dimensiones:
    print(dim)

# Reasignamos la variable completa
dimensiones = (400, 100) 
print("Dimensiones modificadas:")
for dim in dimensiones:
    print(dim)
```

**¿Cuándo usar tuplas?**

Úsalas cuando tengas un conjunto de valores que sabes que serán constantes durante la ejecución del programa (días de la semana, coordenadas fijas, configuraciones de hardware, etc.).

## 2\. Diccionarios

Las listas son estupendas; pero, para encontrar algo, necesitas saber su **índice** (su número de posición: 0, 1, 2...).

¿Pero qué pasa si queremos guardar información de un usuario? ¿Es mejor saber que su nombre está en la posición `0` y su edad en la `1`, o es mejor poder pedir directamente el "nombre" y la "edad"?

Aquí entran los **diccionarios**. Funcionan igual que un diccionario de papel: buscas una palabra (**clave**) y obtienes su definición (**valor**).

### Sintaxis básica

Los diccionarios usan **llaves `{}`**. Dentro, escribimos pares de `clave : valor`.

```python
# Un diccionario que representa a un gato
mi_gato = {
    'tamaño': 'grande', 
    'color': 'gris', 
    'tipo': 'ruidoso'
}
```

### Accediendo a los valores

Para acceder a los valores del diccionario, usamos las claves que hemos escrito.

```python
print(mi_gato['tamaño']) # Muestra 'gordo'
print(f"Mi gato tiene el pelo {mi_gato['color']}.") 
```

### Modificando y añadiendo datos

A diferencia de las tuplas, los diccionarios son **mutables** (se pueden cambiar). No importa el orden, importa la clave.

```python
alumno = {'nombre': 'Pedro', 'edad': 15}

# Añadir un nuevo dato
alumno['curso'] = '4º ESO'

# Modificar un dato existente
alumno['edad'] = 16

print(alumno)
# Resultado: {'nombre': 'Pedro', 'edad': 16, 'curso': '4º ESO'}
```

### El error más común: `KeyError`

Si intentas buscar una clave que no existe, Python fallará.

```python
spam = {'nombre': 'Pedro', 'edad': 15}
# print(spam['color']) # ¡Error! KeyError: 'color'
```

Para evitar esto, tenemos un método muy útil llamado `.get()`.

#### El método `.get()`: La red de seguridad

El método `.get()` intenta buscar una clave, pero si no la encuentra, devuelve un valor por defecto que tú elijas (o `None` si no pones nada). **Esto evita que el programa se rompa.**

```python
materiales = {'manzanas': 5, 'vasos': 2}

print(f"Traigo {materiales.get('vasos', 0)} vasos.")
# Muestra: Traigo 2 vasos. (La clave 'vasos' existe)

print(f"Traigo {materiales.get('huevos', 0)} huevos.")
# Muestra: Traigo 0 huevos. (La clave 'huevos' NO existe, devuelve 0)
```

### Recorriendo diccionarios con bucles `for`

Podemos usar bucles `for` para leer un diccionario, pero tenemos tres formas de hacerlo gracias a tres métodos:

1.  `.keys()`: Devuelve solo las claves (es el comportamiento por defecto).
2.  `.values()`: Devuelve solo los valores.
3.  `.items()`: Devuelve ambos (clave y valor) en forma de tuplas.

```python
spam = {'color': 'rojo', 'edad': 42}

# 1. Solo valores
print("--- Valores ---")
for valor in spam.values():
    print(valor)

# 2. Clave y Valor (Muy útil)
print("\n--- Clave y Valor ---")
for clave, valor in spam.items():
    print(f"La clave es '{clave}' y el valor es {valor}")
```

### Comprobar si una clave existe (`in`)

Igual que en las listas, podemos usar `in` para saber si una **clave** existe antes de usarla.

```python
ordenador = {'cpu': 'i7', 'ram': '16GB'}

if 'grafica' in ordenador:
    print(f"Tiene gráfica: {ordenador['grafica']}")
else:
    print("Este ordenador no tiene tarjeta gráfica dedicada.")
```

### Uso de `.setdefault()`

A veces queremos añadir un valor solo si la clave **no existe todavía**.

Ejemplo: Contar cuántas veces aparece cada letra en una frase.

```python
mensaje = 'Hola a todos los alumnos de SMR'
conteo = {} # Diccionario vacío

for letra in mensaje:
    # Asegura que la letra esté en el diccionario con valor 0 si es la primera vez
    conteo.setdefault(letra, 0)
    
    # Sumamos 1 a la cuenta
    conteo[letra] = conteo[letra] + 1

print(conteo)
```

> **Tip Pro: `pprint` (Pretty Print)**
> Cuando los diccionarios son muy grandes, se ven fatal en la consola. Python tiene un módulo llamado `pprint` que los imprime "bonitos" y ordenados.

```python
import pprint

# Usando el ejemplo anterior
pprint.pprint(conteo)
```

*Esto mostrará cada letra en una línea separada y ordenada, mucho más fácil de leer.*

### 4. Contador de vocales
