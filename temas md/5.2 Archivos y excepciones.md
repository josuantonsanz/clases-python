# Archivos y excepciones en Python

Hasta ahora, cuando cerrábamos nuestros programas, toda la información se perdía. Las variables y listas desaparecían de la memoria.

Para crear programas reales y útiles, necesitamos **persistencia**: guardar datos en el disco duro. En esta clase aprenderemos a:

1.  Leer archivos de texto.
2.  Escribir y guardar información.
3.  Gestionar errores (Excepciones) para que el programa no se "rompa".
4.  Guardar estructuras de datos (como listas) usando JSON.

## 1. Leyendo archivos

Para leer un archivo, primero necesitamos tener uno. Imagina que tenemos un archivo llamado `pi_digits.txt` en la misma carpeta que nuestro script de Python con este contenido:

```text
3.1415926535
  8979323846
  2643383279
```

### La función `open()` y el bloque `with`

Para abrir un archivo usamos `open()`. Pero hay un truco importante: usar la palabra clave `with`.

```python
with open('pi_digits.txt') as fichero:
    contenido = fichero.read()
    print(contenido)
```

**¿Por qué usamos `with`?**

Cuando abres un archivo, el sistema operativo lo "bloquea". Si te olvidas de cerrarlo (con `.close()`), puedes causar errores o corrupción de datos. El bloque `with` se encarga de **cerrar el archivo automáticamente** en cuanto termina el bloque de código, incluso si hay errores. Es la forma segura de trabajar.

### Leyendo línea por línea

A veces no queremos leer todo el archivo de golpe (imagina un archivo de 5GB). Podemos recorrerlo línea a línea con un bucle `for`:

```python
filename = 'pi_digits.txt'

with open(filename) as fichero:
    for linea in fichero:
        print(linea.strip()) # Usamos strip() para quitar saltos de línea extra
```

### Guardar las líneas en una lista

Si quieres guardar el contenido para usarlo después de cerrar el archivo, usa `.readlines()`:

```python
with open(filename) as fichero:
    lineas = fichero.readlines() # Guarda cada línea como un elemento de una lista

print(f"El archivo tiene {len(lineas)} líneas.")
```

> **Tip para Windows:**
> En Windows, las rutas de archivos usan barras invertidas (`\`), pero en Python puedes (y debes) usar barras normales (`/`) incluso en Windows. Es más compatible.
> Ej: `open('datos/mi_archivo.txt')`

## 2. Escribiendo en archivos

Para escribir, pasamos un segundo argumento a la función `open()`. Este argumento indica el **modo**:

*   `'r'`: Lectura (Read). Es el modo por defecto.
*   `'w'`: Escritura (Write). **¡Cuidado!** Si el archivo ya existe, **lo borra** y empieza de cero.
*   `'a'`: Añadir (Append). Escribe al final del archivo sin borrar lo anterior.
*   `'r+'`: Lectura y escritura.

### Escribiendo un archivo nuevo (`'w'`)

```python
nombre_archivo = 'programacion.txt'

with open(nombre_archivo, 'w') as fichero:
    fichero.write("Me encanta programar.\n")
    fichero.write("Es muy útil para automatizar tareas.\n")
```

> **Nota:** `write()` no añade saltos de línea automáticamente. Tienes que añadir `\n` tú mismo.

### Añadiendo contenido (`'a'`)

Si queremos agregar líneas sin borrar lo que había:

```python
with open(nombre_archivo, 'a') as fichero:
    fichero.write("También me gusta gestionar redes.\n")
```

## 3. Excepciones: Gestionando errores

Como administradores de sistemas, sabemos que las cosas fallan: archivos que no existen, usuarios que meten datos incorrectos, discos llenos...

Si ocurre un error, Python detiene el programa y muestra un *Traceback* (ese texto rojo feo). Podemos evitar que el programa se cuelgue usando bloques `try-except`.

### El bloque `try-except`

Le decimos a Python: "Intenta hacer esto (`try`). Si ocurre este error específico, haz esto otro (`except`)".

**Ejemplo clásico: División por cero**

```python
try:
    print(5 / 0)
except:
    print("¡No puedes dividir por cero, amigo!")
```
*El programa no se rompe, solo imprime el aviso y continúa.*

### Gestionando archivos que no existen (`FileNotFoundError`)

Esto es vital cuando pedimos al usuario que abra un archivo.

```python
archivo = 'no_existo.txt'

try:
    with open(archivo) as f:
        contenido = f.read()
except FileNotFoundError:
    print(f"Lo siento, el archivo '{archivo}' no se encuentra en el sistema.")
```

### El bloque `else` y `pass`

*   `else`: Se ejecuta solo si el bloque `try` funcionó correctamente.
*   `pass`: Si queremos que el error falle en silencio (sin decir nada), usamos `pass` en el except.

```python
try:
    resultado = 10 / 2
except:
    print("Error de cálculo")
else:
    # Esto solo se ejecuta si la división salió bien
    print(f"El resultado es {resultado}")
```

### El bloque `finally`

Hay un cuarto bloque en la gestión de errores: `finally`. El código que pongas dentro de `finally` se ejecutará **SIEMPRE**, ocurra un error o no.

Esto es vital en administración de sistemas. Imagina que abres una conexión a una base de datos. Si hay un error a mitad de camino, quieres asegurarte de cerrar esa conexión para no dejar el servidor colgado.

```python
try:
    print("Abriendo conexión con el servidor...")
    resultado = 10 / 0  # Simulamos un error grave
    print("Enviando datos...") # Esto nunca se ejecutará
except:
    print("¡Error detectado! No se pudieron enviar los datos.")
finally:
    print("Cerrando conexión y liberando recursos...")
```

**Salida del programa:**

```text
Abriendo conexión con el servidor...
¡Error detectado! No se pudieron enviar los datos.
Cerrando conexión y liberando recursos...
```

Como ves, aunque hubo un error, la "limpieza" del final se ejecutó igual.

*   **`try`**: Código que podría fallar.
*   **`except`**: Qué hacer si falla.
*   **`else`**: Qué hacer si **NO** falla.
*   **`finally`**: Qué hacer **SIEMPRE** (limpieza).

## 4. Guardando datos complejos con JSON

Los archivos de texto (`.txt`) solo guardan cadenas. ¿Qué pasa si quiero guardar una lista de usuarios o la configuración de un servidor?

Usamos el módulo `json`. JSON es un formato estándar en la industria para intercambiar datos.

Primero, necesitamos importarlo: `import json`

### Guardar datos (`json.dump`)

```python
import json

numeros = [2, 3, 5, 7, 11, 13]
archivo = 'numeros.json'

with open(archivo, 'w') as f:
    json.dump(numeros, f) # Guarda la lista en el archivo
```

### Cargar datos (`json.load`)

```python
import json

archivo = 'numeros.json'

with open(archivo) as f:
    datos_recuperados = json.load(f) # Lee el archivo y lo convierte en lista de Python

print(datos_recuperados)
# Resultado: [2, 3, 5, 7, 11, 13]
```

Esto es muy útil para guardar preferencias de usuario o estados del programa.

### 1. El registro de accesos (Logs)

Imagina que eres el administrador de un servidor y quieres llevar un registro de qué usuarios entran al sistema.

1.  Crea un programa que pida al usuario: **"Introduce tu nombre de usuario para acceder:"**.
2.  Abre (o crea) un archivo llamado `accesos.log` en modo "añadir" (`append`).
3.  Escribe en el archivo una línea que diga: `"Usuario [NOMBRE] ha entrado al sistema."` (recuerda añadir el salto de línea `\n`).
4.  Ejecuta el programa 3 veces con nombres distintos y luego abre el archivo de texto para comprobar que están los tres nombres.

> **Pista:** Usa `open('accesos.log', 'a')`.

### 2. El bloqueador de webs (Lectura)

Tienes un archivo de texto llamado `blacklist.txt` que contiene una lista de sitios web prohibidos en la empresa.

1.  Crea manualmente el archivo `blacklist.txt` en la misma carpeta que tu script y escribe dentro:
    ```text
    facebook.com
    instagram.com
    juegos.com
    tiktok.com
    ```
2.  Crea un script de Python que abra ese archivo en modo lectura.
3.  Recorre el archivo línea por línea e imprime para cada una: **"Bloqueando acceso a: [DOMINIO]"**.
4.  **Importante:** Al imprimir, asegúrate de que no salgan líneas en blanco extra entre medias (usa `.strip()` para limpiar la línea leída).

### 3. Recuperación de configuración (Excepciones)

Vas a crear un script que intenta cargar la configuración de un Router.

1.  Intenta abrir un archivo llamado `config.txt` en modo lectura.
2.  Si el archivo existe, lee su contenido e imprime: **"Configuración cargada: [CONTENIDO]"**.
3.  Si el archivo **NO** existe (captura el error `FileNotFoundError`), el programa no debe fallar. En su lugar, debe imprimir: **"¡Aviso! No se encontró config.txt. Cargando configuración por defecto..."**.

> **Prueba:** Ejecuta el programa primero sin crear el archivo (debería saltar el aviso) y luego crea el archivo `config.txt` con algún texto dentro y vuelve a ejecutarlo.
